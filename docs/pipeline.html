Search Tree Structure

flowchart TD
    ROOT["root/\nskill.md  packet.json\nstats.json  log.log  sandbox/"]
    ROOT --> P0["proposal_0/\ndiff.py  skill.md  prior.json\npacket.json  stats.json"]
    ROOT --> P1["proposal_1/\ndiff.py  skill.md  prior.json\npacket.json  stats.json"]
    P0 --> P00["proposal_0/\n…"]
    P0 --> P01["proposal_1/\n…"]
    P1 --> P10["proposal_0/\n…"]

Each node is self-contained. Reflector reads log.log + sandbox/ to write child proposals. PUCT = Q + c·P·√N_parent / (1 + N_child)
